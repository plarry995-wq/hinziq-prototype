Production readiness

Not yet production-ready

Before real institutional use, HINZIQ needs authenticated user accounts, database-backed permissions, encrypted storage, backups, audit logging, approved retention rules, security testing and institutional workflow validation.

This initial package is a visual and workflow prototype. Demo role switching is not real authentication, and local changes are not shared between users.
